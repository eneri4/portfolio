Acceleration of Convolutional Neural Networks

01 — OVERVIEW

Implementation of convolution, ReLu activation, and max- pooling to an FPGA using SystemVerilog by translating machine learning models from software to hardware using memory layout and control logic

02 — LEARNING GOALS
  • What are the layers of a CNN?
  • How are CNN layers encoded?
  • What design choices need to be made to adapt code to fit an FPGA?

04 — REFLECTION

The biggest takeaway from this project was to draw everything, especially when there are multiple layers to something. Understanding the function behind each layer was a critical foundation for us to apply our design decisions on to quantize our model and ensure timing between each step was precise and accurate.

In the future, I would improve this algorithm by integrating each step to create a true accelerator and test real images instead of simulated ones.
